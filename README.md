## :toolbox: Getting Started

<!-- Prerequisites -->

### :bangbang: Prerequisites

This project uses [pnpm](https://pnpm.io/) as package manager:

```bash
npm install --global pnpm
```

<!-- Run Locally -->

### :running: Run Locally

Clone the project:

```bash
git clone https://github.com/v-bible/i18n.git
```

Go to the project directory:

```bash
cd i18n
```

Install dependencies:

```bash
pnpm install
```

<!-- Usage -->

## :eyes: Usage

### Translation coverage with Lunaria dashboard

Build the Lunaria dashboard:

```bash
pnpm lunaria:build
```

Start the Lunaria dashboard:

```bash
pnpm lunaria:preview
```

## :gem: Acknowledgements

Here are useful resources and libraries that we have used in our projects:

- [Fink](https://fink.inlang.com/): Fink is a translation management platform
  that helps you manage your translations in one place.
- [i18next](https://www.i18next.com/): i18next is an internationalization-framework
  written in and for JavaScript.
- [Lunaria](https://lunaria.dev/): Lunaria is the way to manage your OSS project's
  localization.
